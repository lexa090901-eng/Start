# СТАРТ — Telegram-бот цифровых продуктов

Пакет содержит код бота, три PDF-материала и `render.yaml` для развёртывания на Render через GitHub.

## Что умеет бот

- `/start` — каталог продуктов;
- бесплатный чек-лист;
- `/terms`, `/support`, `/paysupport`;
- принимает оплату цифровых товаров через Telegram Stars (XTR);
- проверяет успешный платёж и автоматически отправляет соответствующий PDF.

## Развёртывание на Render

1. Создайте приватный репозиторий на GitHub и загрузите в него все файлы из этого пакета. Не загружайте настоящий токен и не создавайте `.env` с секретами в репозитории.
2. В Render подключите GitHub, выберите **New → Blueprint** и укажите этот репозиторий с `render.yaml`.
3. При создании добавьте секреты `TELEGRAM_BOT_TOKEN` (токен из BotFather) и `WEBHOOK_SECRET` (длинная случайная строка). Секреты вводите только в Render, не в переписку.
4. Нажмите Apply/Deploy и дождитесь успешного статуса.
5. Откройте `https://t.me/Gfshchchfbot`, нажмите Start, проверьте каталог и бесплатный чек-лист. До реальной продажи выполните контролируемую тестовую покупку Stars.

`render.yaml` использует бесплатный веб-сервис с webhook-режимом. У бесплатного сервиса возможны простои/пробуждение после периода без активности; для более надёжной круглосуточной работы может потребоваться платный постоянно работающий сервис. Не считайте запуск подтверждённым, пока не пройдены проверки в Telegram и в логах Render.

## Важное про оплату

- Цифровые товары, продаваемые внутри Telegram-бота, должны оплачиваться Telegram Stars. Нельзя заменять Stars внешней оплатой картой/СБП внутри бота.
- Для оплаты картой/СБП на отдельном сайте нужен одобренный провайдер и отдельная интеграция checkout. В России самозанятому можно изучить условия ЮKassa: https://yookassa.ru/platezhi-dlya-samozanyatyh/ . Одобрение не гарантировано.
- Цены 99 / 149 / 199 ⭐ — временные технические значения, а не рублёвый эквивалент. Перед продажами подтвердите цены.
- Условия в `TERMS` — черновик. До запуска заполните обязательные данные продавца, условия возврата и поддержки, проверьте применимые требования закона и учёт/чеки в «Мой налог».
- Токен бота, ключи платёжного провайдера и другие секреты не публикуйте и не отправляйте в чат.

## Локальный запуск для проверки

Требуется Python 3.11+.

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN='токен-из-BotFather'
python bot.py
```

При локальном запуске без `RENDER_EXTERNAL_URL` и `WEBHOOK_SECRET` бот использует polling. В Render используются автоматически предоставляемый `RENDER_EXTERNAL_URL` и секрет `WEBHOOK_SECRET` для защищённого webhook.
